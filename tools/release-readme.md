# 妖星 P4

双击 `P4Overlay.exe`，打开独立的机制录入窗和透明结果窗。运行需要 Microsoft Edge WebView2 Runtime。

- 默认紫色主题。两个窗口均可拖动、缩放、置顶。
- 按“大十字1 → 卡奥斯1 → 大十字2 → 卡奥斯2”录入，结果实时同步。
- 每轮显示对应机制真假，水雷、石化、炸弹分别标注；未录入时显示“未记录”。
- 点击底部“流程图”查看 Word 中的9张 P4 流程原图，可翻页、选择步骤、放大缩小、适应窗口。原图已内置，无需联网。左右方向键翻页，+ / − 缩放，Esc 关闭。
- 可选模块默认关闭，按需启用鸳鸯锅、冰雷存储／放出；关闭后不展示或推导对应结果。
- 炸弹仍需记录由哪次大十字发放：真则静止，假则移动，两轮水雷都执行自己的动作。
- 水雷和炸弹同一行显示“雷出去／水出去 · 炸弹禁止／炸弹移动”，同波处理；下一行显示随后判定的“石化出／进”。
- “外观”中可调整字体大小（80%～160%）、语言、背景、文字及强调色；两个窗口同步并自动保存。“默认大小”恢复100%，不改配色。
- 录入窗按钮按状态切换“打开结果框 / 关闭结果框”，与结果窗关闭按钮、F9 同步。关闭结果框会保留数据；关闭录入窗退出程序。

快捷键均为 Ctrl + Alt 加：F8 切换结果窗穿透，F9 显隐结果窗，F10 下一轮，F7 上一轮。录入窗不受结果窗穿透影响。

`locales/zh-CN.json` 为全部中文，`locales/en-US.json` 为英文。只改右侧文字，保留键名与 `{count}` 等占位符，UTF-8 保存后重启即可生效。修改翻译不需要重新编译。

工具只做手动记录，不识别画面、不读取游戏内存、不自动操作游戏。建议游戏使用无边框窗口模式。
